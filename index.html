Crypto Trading Journal & Daily Analytics

Aplikasi berbasis Python untuk mengotomatisasi pencatatan riwayat trading crypto, menghitung statistik harian, serta mengevaluasi win rate dan rasio untung-rugi (risk-to-reward) secara akurat.

  • Mengolah data transaksi mentah untuk menghitung total profit/loss (PnL) harian secara otomatis
  • Menerapkan logika percabangan dan fungsi matematika untuk menghitung persentase win rate dan performa trading
  • Menyimpan dan mengelola riwayat data perdagangan secara terstruktur menggunakan format file lokal
